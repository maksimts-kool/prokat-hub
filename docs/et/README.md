# Prokat Hubi dokumentatsioon (eesti keeles)

[Maksim_Tsikvasvili_TARpv24_Prokat_Hub.docx](Maksim_Tsikvasvili_TARpv24_Prokat_Hub.docx) on praktilise töö dokumentatsioon, vormistatud Tallinna Tehnoloogiakolledži kirjalike tööde juhendi järgi.

Sisu:

- töö eesmärk, laenutuse reeglid (hind, soodustused, tagatisraha, viivised), lähteülesanne, tehnoloogiad ja ajakava;
- arhitektuur, andmebaasi mudel, REST API ja kasutajaliidese kavand;
- arendus koodinäidetega ja testimine;
- kasutusjuhend rollide kaupa (külaline, klient, töötaja, administraator);
- lisades jooniste ja tabelite loetelu.

Kaustas [`pildid`](pildid) on dokumendi kuvatõmmised (eestikeelne liides, 27.11.2026) ja diagrammid.

Sisukord, jooniste ja tabelite loetelu ning lehekülgede numbrid on Wordi väljad. Pärast teksti muutmist uuenda need: vali kogu tekst (Ctrl+A / Cmd+A) ja vajuta F9.
