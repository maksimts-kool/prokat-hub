# client

The Prokat Hub web client: React 19, TypeScript, Vite, Tailwind CSS 4, shadcn/ui, React Router, TanStack Query with an Orval-generated API client, Lucide icons and Sonner toasts.

## Run

With Docker (from the repository root), together with the API and database:

```bash
docker compose watch
```

Open http://localhost:5173. Code changes are synced into the container and Vite reloads them.

On the host (Node 22.12+ and pnpm):

```bash
cp .env.example .env.local
pnpm install
pnpm dev
```

## Scripts

| Command                             | What it does                    |
| ----------------------------------- | ------------------------------- |
| `pnpm dev`                          | Vite dev server with hot reload |
| `pnpm build`                        | Type-check and build to `dist/` |

## API client

`src/api/generated/` holds typed fetch functions and TanStack Query hooks, one file per controller, generated by [Orval](https://orval.dev) from the API's OpenAPI document (`server/ProkatHub.Api/openapi/prokat-hub.json`). Don't edit it by hand.

After changing an endpoint or DTO in the API:

```bash
cd ../server && dotnet build   # a Debug build on the host rewrites the OpenAPI document
cd ../client && pnpm generate:api
```

Commit the document and the generated files together.

Hooks are named after the method and route, e.g. `useGetApiItems`, `usePostApiRentals`, `useGetApiRentalsOverdue`, `usePostApiRentalsIdMarkLate`:

```tsx
const { data, isPending, error } = useGetApiItems({ Page: 1 })
const markLate = usePostApiRentalsIdMarkLate()
markLate.mutate({ id: rental.id })
```

Every request goes through `apiFetch` in `src/api/http-client.ts`. It prefixes `VITE_API_URL`, adds `Authorization: Bearer <token>` from the token stored by `src/lib/auth-token.ts`, and throws an `ApiError` (with the response's `ProblemDetails`) for non-2xx responses. The shared `QueryClient` is in `src/api/query-client.ts`; the React Query devtools appear in development only.

## Configuration

| Variable       | Default                 | Meaning                                          |
| -------------- | ----------------------- | ------------------------------------------------ |
| `VITE_API_URL` | `http://localhost:8080` | Base URL of the API, read in `src/lib/config.ts` |

## Structure

| Folder                   | Contents                                                                 |
| ------------------------ | ------------------------------------------------------------------------ |
| `src/components/ui/`     | shadcn/ui components (add more with `pnpm dlx shadcn@latest add <name>`) |
| `src/components/layout/` | App layout: header, navigation, mobile menu, footer                      |
| `src/pages/`             | One component per route                                                  |
| `src/router.tsx`         | Route table                                                              |
| `src/api/`               | API client: `apiFetch`, `QueryClient`, generated hooks and models        |
| `src/lib/`               | Helpers, configuration and the stored access token                       |
